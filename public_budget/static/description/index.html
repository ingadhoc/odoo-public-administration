Gestión Presupuestaria Pública

Módulo base del sistema SIPRECO: ejecución presupuestaria completa para organismos públicos.

¿Qué hace?

Implementa el circuito completo de ejecución presupuestaria pública: desde la apertura del Presupuesto anual hasta el registro de pagos, pasando por la gestión de Expedientes Administrativos, Transacciones Presupuestarias con sus compromisos (preventivo) y devengamientos (definitivo), y el circuito de Adelantos de Fondos a empleados y proveedores.

Cada gasto del organismo queda trazado desde el rubro presupuestario (Posición Presupuestaria) hasta el comprobante de pago, con control de saldos disponibles en tiempo real. Los Expedientes se trasladan físicamente entre áreas mediante Remitos, dejando un historial de circulación auditado.

Conceptos clave
Concepto Qué es
Presupuesto El presupuesto anual del organismo. Define los rubros y montos autorizados para el ejercicio.
Posición Presupuestaria Ítem jerárquico del clasificador presupuestario (rubro). Acumula compromisos, devengamientos y pagos. Controla el saldo disponible.
Expediente Carpeta administrativa que agrupa transacciones. Circula físicamente entre áreas del organismo mediante remitos.
Transacción El corazón del circuito: representa un gasto o compromiso. Vincula expediente + presupuesto + proveedor + líneas preventivas/definitivas + órdenes de pago.
Preventivo Compromiso del gasto (reserva el saldo de la posición). Es el primer registro contable de una erogación.
Definitivo Devengamiento: el gasto se reconoce contablemente. Habilita la generación de la factura y la orden de pago.
Remito Constancia de traslado de un expediente entre áreas. Registra origen, destino, fecha y usuario.
Adelanto Entrega de fondos anticipada a un empleado o proveedor. Requiere devolución y rendición posterior.
Flujo principal de ejecución
Apertura del Presupuesto anual (draft → open) → Creación del Expediente (número + carátula + proveedores) → Creación de la Transacción (expediente + tipo + proveedor) → Líneas Preventivas (compromiso → reserva saldo posición) → Líneas Definitivas (devengado → habilita factura) → Factura del proveedor → Orden de Pago → Pago registrado → Pre-cierre / Cierre del Presupuesto al fin del ejercicio
Perfiles de usuario
Área Director Usuario
Habilitaciones Acceso completo. Aprueba requerimientos de adelanto. Opera expedientes y transacciones de su área.
Contaduría Acceso completo. Confirma adelantos. Carga facturas y órdenes de pago.
Secretaría Puede anular y cerrar expedientes. Gestión de expedientes y remitos.
Portal Expedientes Solo lectura de expedientes y transacciones vinculadas.
Ciclos de vida principales

Presupuesto:

Borrador → Abierto → Pre-cerrado → Cerrado  (o Cancelado)

Transacción:

Borrador → Abierta → Cerrada  (o Cancelada)

Solicitud de Adelanto:

Borrador → Aprobado (dir. habilitaciones) → Confirmado (contaduría)  (o Cancelado)
Reportes disponibles
  • Presupuesto a Fecha — estado de ejecución presupuestaria al día consultado (en Excel).
  • Reporte de Presupuesto — resumen ejecutivo por posición, con preventivo, definitivo, pagado y saldo.
  • Expediente — imprime la carátula y el historial de movimientos del expediente.
  • Remito — comprobante de traslado del expediente entre áreas.
  • Transacción — detalle de compromisos y pagos de una transacción.
  • Orden de Pago / Recibo de Pago — documentos de respaldo del pago.
  • Lista de Pagos — listado consolidado de órdenes de pago.
  • Análisis de Adelantos / Deuda de Adelantos — seguimiento de adelantos pendientes de rendición.
  • Activos — altas, bajas, modificaciones y listado de bienes inventariables vinculados a transacciones.
  • Modificaciones Presupuestarias — movimientos de fondos y ampliaciones entre posiciones.
Validaciones principales
⚠️ Solo se pueden crear transacciones contra un presupuesto en estado Abierto. Las transacciones de un presupuesto cerrado quedan en solo lectura.
⚠️ El expediente debe estar en la ubicación del usuario para poder vincularle transacciones nuevas. Un expediente en tránsito (remito emitido pero no recibido) no está disponible.
⚠️ No se puede cancelar una Solicitud de Adelanto si ya tiene órdenes de pago activas. Hay que anular los pagos primero.
ℹ️ El saldo de cada Posición Presupuestaria se calcula en tiempo real: Autorizado − Preventivo = Saldo disponible. Si el preventivo supera el autorizado, el sistema bloquea el alta de nuevas líneas.
