Código de Posiciones Presupuestarias

Codificación jerárquica automática para la estructura presupuestaria pública.

¿Qué hace?

Este módulo amplía la gestión de posiciones presupuestarias incorporando un sistema de codificación jerárquica automática: cada posición tiene un Código Individual que se combina con el de su nodo padre para formar el código completo de la cadena.

Cuando el usuario asigna un código individual a un nodo, el sistema concatena automáticamente ese código con el de todos sus ancestros, generando el Código completo sin necesidad de escribirlo a mano. Si se mueve el nodo a otra rama, el código se recalcula solo.

Cómo usarlo
  1. Abrir la Posición Presupuestaria desde el menú correspondiente.
  2. Completar el campo Código Individual con el tramo propio de ese nodo (ej: 01, 07).
  3. Guardar. El campo Código se actualiza automáticamente como concatenación del código del padre más el código individual.
Padre "Gastos Corrientes" → Código: 1 Hijo "Personal" → Código Individual: 01 → Código: 101 Nieto "Planta Permanente" → Código Individual: 01 → Código: 10101
Campos agregados
Campo Qué es
Código Individual Tramo propio del nodo, asignado manualmente. El usuario lo edita.
Código Código completo calculado: padre + código individual. Solo lectura.
ℹ️ Si una posición no tiene padre (nodo raíz), su Código completo es igual a su Código Individual.
